# TOWER 004 — Drag programming board
Extends PR #213. Feature Desk on /fm/load/#feature-desk now offers a searchable shared approved-recording palette and independent station draft running order. Drag a palette handle to any insertion line or row, drag existing occurrences to reorder, or use Add/up/down/remove on touch and keyboard. Exact duplicate occurrences are supported. Undo is one order edit per current draft, reset on station switch or successful save. Cue offsets are estimates from known durations, not a clock or aircheck; unknown durations prevent subsequent exact offsets. Drafts stay tab-local.
The pure order contract rejects wrong station, stale revision, wrong occurrence, ineligible source and over-limit insertions. Drop changes only the draft; existing owner/eligibility rechecks and source-verified export paths remain. No live skip, queue mutation, automatic publication or secondary control authority. Desktop live drag-and-drop is unchanged.
Validation: ten synthetic order/offset checks and static ID audit passed; tests/tower-feature-order.test.mjs records regression cases. Real browser pointer/touch/keyboard interaction and CI remain pending. No deployment or broadcaster change.
