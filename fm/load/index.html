    03 · Desktop folder reader

    Choose the parent folder containing your music subfolders. Nothing is uploaded or made public just by selecting a folder. A file's path can fill artist and album before you review each recording.

    Available fields: artist, album, genre, collection, disc, ignore. Extra outer folders are skipped. Artist and album are saved to the radio catalog; the other fields are preview context for now.

    Folder layout: Artist / Album. The chosen parent folder itself is not treated as an artist.

    For an existing Acer Tower crate, select %LOCALAPPDATA%\HUMKIN\Tower\media using the folder picker. SHA-named audio and paired JSON sidecars are read locally to restore titles, artists, albums and verified durations before any upload. Original paths remain on your computer; missing sidecars are flagged for review.

        Field notes

        ✳ OPEN MESH · INDEX EVERY COMPUTER ↗

        Keep originals on your phone or computer; this loader makes listening copies, not archival masters. Upload failures leave the unshared source untouched. Exact duplicates are skipped by SHA-256. A locked screen may suspend uploads, so leave this tab visible while a crate is transferring.

        For hundreds of WAVs, a desktop FFmpeg batch conversion is faster and more reliable than encoding on a phone. The repo also includes a local offline converter at tools/humkin-radio-batch.py. Make MP3s once, then select the resulting folder here. Direct R2 allows up to three parallel recordings (50 MiB each); interrupted batches can be resumed by reselecting the same folder or retrying errors. Individual PUTs restart on network failure.
