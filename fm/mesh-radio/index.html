01 · Bring the whole scattered library

Import inventory JSONs from multiple computers, even if they're currently offline. This indexes recording fingerprints and copy counts. It does not move audio or make remote drives accessible.

R2 is simply one source. Published recordings can become playable immediately; local-only inventory entries stay indexed until a playable source is attached.

Listen to music on this device, without uploading

Selected files are fingerprinted one at a time and played locally using browser file URLs. No audio upload. You must reselect files after restarting the browser; the catalog of links remains.

02 · Add another free host

Mirror a known recording on R2, Supabase public Storage, a personal HTTPS server, or another host. Its recording fingerprint stays the same. This form registers a playable location; it does not upload the bytes.

Permanent routes must be public HTTPS URLs without credentials. Local/private files are never exposed by exporting a manifest.

Portable linkblocks

Exports contain titles, fingerprints, node labels, station recipes, and approved public URLs. No local filenames, passwords, private folder paths, or listening history. Review an export before sharing.

03 · The Compost Heap

Prioritizes the least-played recordings that have a playable source here. Playback tries another linked source if the first audio URL fails. Device-only entries stay in the catalog, but can't stream from an offline machine yet.
