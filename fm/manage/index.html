TOWER / 04

Automation

Control the cadence and relationships that shape rotation.

02 · AUTOMATIC DJ

All published, enabled STATION BUMPERS share one library, regardless of origin. Short IDs (≤19s) pop up on an irregular φ (golden-ratio) rhythm. A medium-or-long feature plays about every 11–12 minutes: medium cuts (20–59s) between the longer (60s+) features, which recur about every 22–23 minutes. Same weight inside each length group; more slots for short sounds. No overlapping or interrupted songs. Only active owner-authored rules and disabled/unpublished files can suppress a bumper. All former inferred holds are OFF.

✳ CLOUDFLARE R2 · MEDIA VAULT

Checking the cloud record cabinet…

Every recording has an authoritative storage location. Published Supabase music can be copied to R2 without interrupting playback. Transfers verify the SHA-256 checksum, object size and public delivery before switching the catalog. Redundant copies may be reclaimed by the separately deployed maintenance job. Manual migration and reclamation remain recovery controls; avoid running manual reclamation while the automatic job is active.
