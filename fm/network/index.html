WHAT THE WEAVE DOES

KINSHIP PRODUCER LAW → sourced proposal → human review → READY ≠ AIRED → confirmed on-air occurrence → truthful return.
ROCK IMPACT / STREAM-001 LAW → source and scene preflight → record first → go live → preserve even if the network fails.
HUMKIN ACTUAL RADIO → owned musical catalog → producer carts and scheduled shows → dedicated transmitter → one uninterrupted stream for listeners.

For original HUMKIN segments, the Production Room can prepare private carts. The Living Discography producer desk already preserves manual review, AIR/RETURN transitions and station memory. Both require human action; neither publishes third-party audio without explicit authorization.
